Help & Usage

      
    

    

      

        
Exporting from Dialogflow ES

        
    
          
  1. Open your agent in the Dialogflow console
    2. 
          
  2. Go to Settings → Export and Import
    3. 
          
  3. Click Export as ZIP and download
    4. 
          
  4. Drop the .zip here or click Load Agent
    5. 
        

      

      

        
Editing & Creating Flows

        
    
          
  • Click ✏ Edit to enter edit mode
    • 
          
  • Click any node to open its edit form — modify response, contexts, training phrases, and quick replies
    • 
          
  • Click ＋ Intent to create a brand-new intent — connect it by sharing context names with existing intents
    • 
          
  • Connections are made through contexts: intent A sets output context ctx_foo, intent B lists ctx_foo as input → an arrow appears
    • 
          
  • Click ↓ Export ZIP to download a Dialogflow-importable ZIP
    • 
          
  • In Dialogflow: Settings → Export and Import → Import from ZIP
    • 
          
  • Click the agent name pill (top left) to rename in edit mode
    • 
        

      

      

        
Visualizer Controls

        
    
          
  • Click a node — view or edit intent details in the right panel
    • 
          
  • Scroll to zoom · drag background to pan · Fit resets viewport
    • 
          
  • Entities panel lists custom entity definitions from the ZIP
    • 
          
  • Simulate opens a draggable chat widget to test the flow live
    • 
        

      

      

        
Node Types

        
    
          
  • 🏠 Entry — WELCOME event / conversation start
    • 
          
  • 📋 Data — collects parameters (slot-filling)
    • 
          
  • ❓ Intent — standard conversational turn
    • 
          
  • ⚠️ Fallback — context-scoped fallback handler
    • 
          
  • 🚫 Global Fallback — catches any unmatched input
    • 
          
  • ✅ Terminal — end of conversation
    • 
        

      

      

        
Caveats

        

          
NLU is approximate — keyword/phrase matching, not ML

          
Webhook fulfillment is not executed in simulation

          
Only English training phrases exported (_usersays_en.json)

          
Only Dialogflow ES is supported — not CX

          
All processing is local — no data leaves your browser
